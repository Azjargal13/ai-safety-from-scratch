# AI Safety from Scratch

A personal knowledge base of **AI Safety**, built from the ground up as I learn it.

This repository starts from the earliest serious warnings about intelligent machines and goes all the way to the current state of the field as of **October, 2026**. It is primarily my own learning notebook, written in public so that other beginners can follow along.

> “It seems probable that once the machine thinking method had started, it would not take long to outstrip our feeble powers… At some stage therefore we should have to expect the machines to take control.”  
> — **Alan Turing**, *Intelligent Machinery, A Heretical Theory* (1951)

## Why this repository exists

I want to understand AI Safety properly — the history, the core problems, the technical ideas, and what people are actually doing about it today.

Instead of just collecting random links and notes, I’m organizing everything I learn into a clear structure. This helps me:

- Build real understanding step by step
- See how the field developed over time
- Keep track of what still confuses me
- Create something that other beginners might also find useful

## Repository Structure

```text
├── 00-start-here/                 ← Begin here
├── 01-history/                    ← From 1951 to 2026
├── 02-core-concepts/              ← Key ideas explained simply
├── 03-technical-approaches/       ← Methods and techniques
├── 04-organizations-and-people/   ← Who is working on this
├── 05-key-papers-and-resources/   ← Important reading
├── 06-current-state/              ← Snapshot of the field (living section)
├── 07-learning-and-practice/      ← Courses, experiments, next steps
└── 08-quotes-and-primary-sources/ ← Original texts
```
